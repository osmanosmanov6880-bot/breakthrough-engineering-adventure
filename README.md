# BREAKTHROUGH — «Помоги воде попасть в бутылку»

Работающий **автономный** прототип первого игрового урока инженерной платформы BREAKTHROUGH. Интерфейс на русском. Не требует регистрации, серверной базы данных, npm, CDN, API-ключей и доступа к интернету.

## Как запустить

**Самый простой способ:** откройте `index.html` в Chrome, Edge или Firefox (двойным щелчком). Потребуется браузер с WebGL для объёмной сцены. Если WebGL недоступен, логика урока, кнопки и индикаторы сохраняют работоспособность.

**Через локальный веб-сервер:**

```bash
cd breakthrough-adventure-prototype
python -m http.server 4173
```

Затем откройте `http://127.0.0.1:4173`.

## Что реализовано

- 3D-сцена (WebGL): модель бака на стойке, трубка, управляемый кран, бутылка, вода, динамический поток.
- 3D-модель можно вращать и масштабировать; кран нажимается на самой установке либо кнопкой.
- Знакомство, опыт с наполнением, объяснение причины, эксперимент с 0–100% открытия крана, предсказание, проверка, самостоятельная сборка из 4 деталей, итоговое достижение.
- Модель расхода воды с учётом открытия клапана и уровня в баке. При наполнении объём отнимается от резервуара и добавляется в бутылку, до её ёмкости.
- Сборка: выбор детали и места нажатием либо drag-and-drop; неверный выбор даёт подсказку; модель обновляется в 3D.
- Локальное сохранение состояния в `localStorage` для гостевого режима.
- Адаптивные стили для смартфонов и компьютеров; интерактивные элементы доступные клавиатурой.
- По желанию — системное русскоязычное озвучивание через Web Speech API, если браузер поддерживает его.
- Кнопка печати свидетельства после завершения урока.

## Архитектура

- `index.html` — семантическая оболочка и структура.
- `styles.css` — стили, сетка, состояния, адаптивность.
- `scene.js` — минимальный рендерер WebGL с процедурными 3D-мешами; без внешних библиотек.
- `app.js` — машина состояний урока, упрощённая гидравлическая модель, проверка заданий, управление и прогресс.
- `LESSON_SCENARIO.md` — полный педагогический сценарий, тесты, ограничения.

## Физическая модель

Демонстрационная модель применяет зависимость:

`Q = 112 × α × √(0.76 + 0.24 × Vбак / 1600) мл/с`

где `α ∈ [0,1]` — относительное открытие крана. Баланс жидкости: `ΔVбак = −Q × Δt`, `ΔVбутылка = +Q × Δt`. При отсутствии необходимых компонентов, закрытом кране, пустом баке или полной бутылке поток прекращается.

**Важно:** числовые коэффициенты подобраны для учебной интерактивности. Это упрощённая модель без расчёта фактической гидравлики трубы, потерь, вязкости и реального клапана. Нельзя использовать показания прототипа для конструирования настоящего оборудования.

## Ограничения и дальнейшая интеграция

Это отдельный **прототип урока**, а не изменение исходного репозитория BREAKTHROUGH: архив исходного проекта не предоставлен. Данные хранятся в браузере и не синхронизируются между устройствами. Продвинутых настоящих CAD-инструментов, сервера, профилей учащихся и полного курса здесь нет.

Для внедрения в BREAKTHROUGH нужно изучить код действующей платформы, определить существующий frontend/router/хранилище и встроить модули без удаления работающих функций.
